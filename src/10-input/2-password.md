# <input type="password"> 

```
<input type="password">
```
## Common Attributes for password
| Attribute         | Description                      |
| ----------------- | -------------------------------- |
| `type="password"` | Makes the input a password field |
| `name`            | Sends data with form             |
| `id`              | Unique identifier                |
| `class`           | CSS styling class                |
| `value`           | Default value                    |
| `placeholder`     | Hint text inside input           |
| `required`        | Field must be filled             |
| `readonly`        | Cannot edit value                |
| `disabled`        | Completely disabled              |
| `maxlength`       | Maximum characters               |
| `minlength`       | Minimum characters               |
| `size`            | Visible input width              |
| `autocomplete`    | Browser auto password support    |
| `pattern`         | Custom validation pattern        |
| `autofocus`       | Automatically focus field        |
| `form`            | Connect input to form            |
| `title`           | Extra help message               |
| `spellcheck`      | Enable/disable spell check       |
