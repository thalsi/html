# <input type="week">

<input type="week"> is used to select:

Week + Year

Used for:

Weekly reports
Project planning
Timesheets
Work schedules

⚠ User selects:

Week number
Year

NOT:

Exact date

```
<input type="week">
```

## Common Attributes for week
| Attribute      | Description             |
| -------------- | ----------------------- |
| `type="week"`  | Creates week picker     |
| `name`         | Sends form data         |
| `id`           | Unique identifier       |
| `class`        | CSS styling             |
| `value`        | Default week            |
| `min`          | Minimum selectable week |
| `max`          | Maximum selectable week |
| `required`     | Must select week        |
| `disabled`     | Disables input          |
| `readonly`     | Cannot edit             |
| `autocomplete` | Browser autocomplete    |
| `form`         | Connects to form        |
| `autofocus`    | Auto focus input        |
| `title`        | Extra help message      |
| `inputmode`    | Virtual keyboard mode   |
| `step`         | Week interval           |
