# <input type="time">

<input type="time"> is used to select:

Time
Meeting time
Alarm time
Appointment time

Browser usually provides:

Time picker ⏰

```
<input type="time">
```

## Common Attributes for time
| Attribute      | Description             |
| -------------- | ----------------------- |
| `type="time"`  | Creates time picker     |
| `name`         | Sends form data         |
| `id`           | Unique identifier       |
| `class`        | CSS styling             |
| `value`        | Default time            |
| `min`          | Minimum selectable time |
| `max`          | Maximum selectable time |
| `required`     | Must select time        |
| `disabled`     | Disables input          |
| `readonly`     | Cannot edit             |
| `autocomplete` | Browser autocomplete    |
| `form`         | Connects to form        |
| `autofocus`    | Auto focus input        |
| `title`        | Extra help message      |
| `inputmode`    | Virtual keyboard mode   |
| `step`         | Time interval           |
