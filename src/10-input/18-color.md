# <input type="color">

<input type="color"> creates a:

Color picker

Used for:

Theme color
Background color
Text color
Design customization

Browser usually shows:
🎨 Color selection UI

```
<input type="color">
```

## Common Attributes for color
| Attribute      | Description           |
| -------------- | --------------------- |
| `type="color"` | Creates color picker  |
| `name`         | Sends form data       |
| `id`           | Unique identifier     |
| `class`        | CSS styling           |
| `value`        | Default color         |
| `required`     | Makes field required  |
| `disabled`     | Disables color picker |
| `readonly`     | Prevents editing      |
| `autofocus`    | Auto focus input      |
| `form`         | Connects to form      |
| `title`        | Extra help message    |
