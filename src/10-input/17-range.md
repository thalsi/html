# <input type="range">

<input type="range"> creates a:

Slider control

Used for:

Volume control
Brightness
Price range
Rating
Zoom level

User drags slider:
⬅️ ➖ 🔘 ➖ ➡️


```
<input type="range">
```

Common Attributes for range

| Attribute      | Description                  |
| -------------- | ---------------------------- |
| `type="range"` | Creates slider               |
| `name`         | Sends form data              |
| `id`           | Unique identifier            |
| `class`        | CSS styling                  |
| `value`        | Default slider value         |
| `min`          | Minimum value                |
| `max`          | Maximum value                |
| `step`         | Increment/decrement interval |
| `required`     | Makes field required         |
| `disabled`     | Disables slider              |
| `autofocus`    | Auto focus input             |
| `form`         | Connects to form             |
| `title`        | Extra help message           |
