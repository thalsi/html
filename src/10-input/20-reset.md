# <input type="reset">

<input type="reset"> creates a:

Reset button

Used to:

Reset form fields back to original/default values.

When clicked:

All form inputs return to their initial state.

```
<input type="reset">
```
## Common Attributes for reset

| Attribute      | Description             |
| -------------- | ----------------------- |
| `type="reset"` | Creates reset button    |
| `name`         | Button name             |
| `id`           | Unique identifier       |
| `class`        | CSS styling             |
| `value`        | Button text             |
| `form`         | Connects button to form |
| `title`        | Extra help message      |
