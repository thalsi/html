# <input type="button">

<input type="button"> creates a:

Clickable button

Used mainly with:

JavaScript
Custom actions
UI interactions

⚠ Important:

It does NOT submit forms automatically.

Basic Syntax
```
<input type="button">
```

Default:

Empty button text

So usually use value.

## Common Attributes for button

| Attribute       | Description              |
| --------------- | ------------------------ |
| `type="button"` | Creates custom button    |
| `name`          | Button name              |
| `id`            | Unique identifier        |
| `class`         | CSS styling              |
| `value`         | Button text              |
| `onclick`       | Runs JavaScript on click |
| `form`          | Connects to form         |
| `title`         | Extra help message       |


Which is Better?

✅ <button> preferred for:

Better UI
Icons
Styling

<input> Limitations

<input>:

Cannot contain HTML
Cannot contain icon elements
Cannot contain images inside
Only text via value
