<input type="datetime-local">

<input type="datetime-local"> is used to select:

Date + Time together

Used for:

Meeting schedule
Appointment booking
Event time
Delivery scheduling

⚠ Important:

It does NOT include timezone information.

```
<input type="datetime-local">
```

## Common Attributes for datetime-local

| Attribute               | Description                 |
| ----------------------- | --------------------------- |
| `type="datetime-local"` | Creates date & time picker  |
| `name`                  | Sends form data             |
| `id`                    | Unique identifier           |
| `class`                 | CSS styling                 |
| `value`                 | Default date & time         |
| `min`                   | Minimum allowed date & time |
| `max`                   | Maximum allowed date & time |
| `required`              | Must select value           |
| `disabled`              | Disables input              |
| `readonly`              | Cannot edit                 |
| `autocomplete`          | Browser autocomplete        |
| `form`                  | Connects to form            |
| `autofocus`             | Auto focus input            |
| `title`                 | Extra help message          |
| `inputmode`             | Virtual keyboard mode       |
| `step`                  | Time interval               |
