# <input type="email">

<input type="email"> is used for entering email addresses.

Browser automatically checks:

@
domain name
valid email structure

Example:

test@gmail.com ✅
abc@ ❌

```
<input type="email">
```

## Common Attributes for email
| Attribute              | Description                |
| ---------------------- | -------------------------- |
| `type="email"`         | Creates email input        |
| `name`                 | Sends form data            |
| `id`                   | Unique identifier          |
| `class`                | CSS styling                |
| `value`                | Default value              |
| `placeholder`          | Hint text                  |
| `required`             | Must fill field            |
| `readonly`             | Cannot edit                |
| `disabled`             | Disables field             |
| `maxlength`            | Maximum characters         |
| `minlength`            | Minimum characters         |
| `size`                 | Visible width              |
| `autocomplete="email"` | Browser email suggestions  |
| `inputmode="email"`    | Email keyboard on mobile   |
| `multiple`             | Allow multiple emails      |
| `pattern`              | Custom validation          |
| `autofocus`            | Auto focus input           |
| `form`                 | Connect to form            |
| `title`                | Extra help message         |
| `spellcheck`           | Enable/disable spell check |
