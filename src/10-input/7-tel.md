# <input type="tel">

<input type="tel"> is used for entering telephone/mobile numbers.

It does NOT automatically validate phone numbers because:

Phone formats differ by country.

Used for:

Mobile number
Telephone number
WhatsApp number
Emergency contact

```
<input type="tel">
```
Common Attributes for tel

| -------------------- | -------------------------- |
| `type="tel"`         | Creates telephone input    |
