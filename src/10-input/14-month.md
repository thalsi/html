#<input type="month">

<input type="month"> is used to select:

Month + Year

Used for:

Credit card expiry
Salary month
Report month
Billing month

⚠ User selects:

Month
Year

NOT:

Day

```
<input type="month">
```

## Common Attributes for month

| Attribute      | Description              |
| -------------- | ------------------------ |
| `type="month"` | Creates month picker     |
| `name`         | Sends form data          |
| `id`           | Unique identifier        |
| `class`        | CSS styling              |
| `value`        | Default month            |
| `min`          | Minimum selectable month |
| `max`          | Maximum selectable month |
| `required`     | Must select month        |
| `disabled`     | Disables input           |
| `readonly`     | Cannot edit              |
| `autocomplete` | Browser autocomplete     |
| `form`         | Connects to form         |
| `autofocus`    | Auto focus input         |
| `title`        | Extra help message       |
| `inputmode`    | Virtual keyboard mode    |
| `step`         | Month interval           |
