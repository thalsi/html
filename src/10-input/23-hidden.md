# <input type="hidden">

<input type="hidden"> creates:

A hidden form field

Used to:

Store backend data
Send hidden values
Store IDs/tokens
Pass data silently

⚠ Important:

User cannot see it on page
But value is still sent with form submission

```
<input type="hidden">
```

Common Attributes for hidden
| Attribute       | Description          |
| --------------- | -------------------- |
| `type="hidden"` | Creates hidden field |
| `name`          | Field name           |
| `id`            | Unique identifier    |
| `class`         | CSS styling          |
| `value`         | Hidden value         |
| `form`          | Connects to form     |
