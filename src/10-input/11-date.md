# <input type="date">

<input type="date"> is used to select a:

Calendar date
Birthday
Booking date
Appointment date

Browser usually provides:

Date picker calendar 📅

```
<input type="date">
```
## Common Attributes for date
| Attribute      | Description              |
| -------------- | ------------------------ |
| `type="date"`  | Creates date picker      |
| `name`         | Sends form data          |
| `id`           | Unique identifier        |
| `class`        | CSS styling              |
| `value`        | Default date             |
| `min`          | Minimum selectable date  |
| `max`          | Maximum selectable date  |
| `required`     | Must select date         |
| `disabled`     | Disables input           |
| `readonly`     | Cannot edit              |
| `autocomplete` | Browser date suggestions |
| `form`         | Connects to form         |
| `autofocus`    | Auto focus input         |
| `title`        | Extra help message       |
| `inputmode`    | Virtual keyboard mode    |
| `step`         | Date interval            |
