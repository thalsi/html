# <input type="search">

<input type="search"> is used for:

Search bars
Search boxes
Website search
Product search

It works similar to text, but browsers may provide:

Clear (×) button
Search styling
Better mobile search keyboard

```
<input type="search">
```

## Common Attributes for search

| Attribute       | Description                |
| --------------- | -------------------------- |
| `type="search"` | Creates search input       |
| `name`          | Sends form data            |
| `id`            | Unique identifier          |
| `class`         | CSS styling                |
| `value`         | Default value              |
| `placeholder`   | Hint text                  |
| `required`      | Must fill field            |
| `readonly`      | Cannot edit                |
| `disabled`      | Disables input             |
| `maxlength`     | Maximum characters         |
| `minlength`     | Minimum characters         |
| `size`          | Visible width              |
| `autocomplete`  | Browser search suggestions |
| `list`          | Connects with `<datalist>` |
| `autofocus`     | Auto focus input           |
| `pattern`       | Custom validation          |
| `title`         | Extra help message         |
| `spellcheck`    | Enable/disable spell check |
| `form`          | Connects input to form     |
