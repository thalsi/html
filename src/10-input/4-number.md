# <input type="number">

<input type="number"> is used for numeric input only.

Used for:

Age
Quantity
Price
Marks
PIN
Weight

Browser usually provides:

Up/Down arrows
Numeric validation

```
<input type="number">
```
## Common Attributes for number

| Attribute             | Description                |
| --------------------- | -------------------------- |
| `type="number"`       | Creates numeric input      |
| `name`                | Sends form data            |
| `id`                  | Unique identifier          |
| `class`               | CSS styling                |
| `value`               | Default value              |
| `min`                 | Minimum allowed number     |
| `max`                 | Maximum allowed number     |
| `step`                | Number increment/decrement |
| `placeholder`         | Hint text                  |
| `required`            | Must fill field            |
| `readonly`            | Cannot edit                |
| `disabled`            | Disables input             |
| `autocomplete`        | Browser suggestions        |
| `inputmode="numeric"` | Numeric mobile keyboard    |
| `title`               | Extra help message         |
| `form`                | Connects input to form     |
