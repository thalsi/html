<input type="url">

<input type="url"> is used for entering:

Website links
URLs
Web addresses

Browser automatically checks for a valid URL format.

Example:

https://google.com ✅
google ❌

```
<input type="url">
```


## Common Attributes for url
| Attribute            | Description                |
| -------------------- | -------------------------- |
| `type="url"`         | Creates URL input          |
| `name`               | Sends form data            |
| `id`                 | Unique identifier          |
| `class`              | CSS styling                |
| `value`              | Default value              |
| `placeholder`        | Hint text                  |
| `required`           | Must fill field            |
| `readonly`           | Cannot edit                |
| `disabled`           | Disables input             |
| `maxlength`          | Maximum characters         |
| `minlength`          | Minimum characters         |
| `size`               | Visible width              |
| `pattern`            | Custom URL validation      |
| `autocomplete="url"` | Browser URL suggestions    |
| `inputmode="url"`    | URL keyboard on mobile     |
| `autofocus`          | Auto focus input           |
| `title`              | Extra help message         |
| `form`               | Connects input to form     |
| `spellcheck`         | Enable/disable spell check |
