# HTML Elements Reference — Complete Checklist ✅

## 1. Document & Metadata
- [ ] `<html>` — Root element of an HTML document.
- [ ] `<head>` — Container for metadata (title, meta, links, scripts).
- [ ] `<title>` — Defines the document title (shown in browser tab).
- [ ] `<base>` — Specifies base URL for relative links.
- [ ] `<link>` — Links external resources (CSS, icons, etc.).
- [ ] `<meta>` — Defines metadata (charset, viewport, SEO info).
- [ ] `<style>` — Internal CSS styles.
- [ ] `<script>` — Embeds or links JavaScript code.
- [ ] `<noscript>` — Content shown when scripts are disabled.
- [ ] `<template>` — Defines reusable, hidden HTML content.
- [ ] `<slot>` — Placeholder in Web Components.

## 2. Sectioning & Structure
- [ ] `<body>` — Document body, main content container.
- [ ] `<header>` — Introductory or navigational section.
- [ ] `<nav>` — Defines navigation links.
- [ ] `<main>` — Main content area (unique per page).
- [ ] `<section>` — Thematic grouping of content.
- [ ] `<article>` — Self-contained content (blog, news).
- [ ] `<aside>` — Sidebar or tangential content.
- [ ] `<footer>` — Footer of section or page.
- [ ] `<h1>` to `<h6>` — Headings, from highest to lowest level.
- [ ] `<hgroup>` — Groups multiple headings.
- [ ] `<address>` — Contact or author information.

## 3. Text Content
- [ ] `<p>` — Paragraph.
- [ ] `<br>` — Line break.
- [ ] `<hr>` — Thematic break (horizontal rule).
- [ ] `<pre>` — Preformatted text.
- [ ] `<blockquote>` — Quoted section from another source.
- [ ] `<ol>` — Ordered list.
- [ ] `<ul>` — Unordered list.
- [ ] `<li>` — List item.
- [ ] `<dl>` — Description list.
- [ ] `<dt>` — Term in a description list.
- [ ] `<dd>` — Description of a term.
- [ ] `<figure>` — Self-contained content (image, code, chart).
- [ ] `<figcaption>` — Caption for a figure.

## 4. Inline Text Semantics
- [ ] `<a>` — Hyperlink.
- [ ] `<em>` — Emphasis (italic).
- [ ] `<strong>` — Strong importance (bold).
- [ ] `<small>` — Fine print or side comments.
- [ ] `<cite>` — Citation of a work.
- [ ] `<q>` — Inline quotation.
- [ ] `<dfn>` — Definition term.
- [ ] `<abbr>` — Abbreviation.
- [ ] `<time>` — Date/time.
- [ ] `<code>` — Inline code snippet.
- [ ] `<var>` — Variable in math/code.
- [ ] `<samp>` — Sample output.
- [ ] `<kbd>` — Keyboard input.
- [ ] `<sub>` — Subscript.
- [ ] `<sup>` — Superscript.
- [ ] `<i>` — Idiomatic, technical, or styled text.
- [ ] `<b>` — Stylistic bold (not emphasis).
- [ ] `<u>` — Stylistic underline.
- [ ] `<mark>` — Highlighted text.
- [ ] `<span>` — Generic inline container.
- [ ] `<bdi>` — Isolates text for bi-directional formatting.
- [ ] `<bdo>` — Overrides text direction.
- [ ] `<wbr>` — Word break opportunity.

## 5. Edits
- [ ] `<ins>` — Inserted text.
- [ ] `<del>` — Deleted text.

## 6. Embedded Content
- [ ] `<img>` — Image.
- [ ] `<iframe>` — Inline frame (embed another page).
- [ ] `<embed>` — Embeds external content (e.g. plugin).
- [ ] `<object>` — Generic embedded object.
- [ ] `<param>` — Parameters for `<object>`.
- [ ] `<video>` — Video player.
- [ ] `<audio>` — Audio player.
- [ ] `<source>` — Media source for `<video>`/`<audio>`.
- [ ] `<track>` — Text tracks (subtitles, captions).
- [ ] `<picture>` — Responsive images container.
- [ ] `<map>` — Image map.
- [ ] `<area>` — Clickable area in an image map.
- [ ] `<canvas>` — Drawing surface for graphics.
- [ ] `<svg>` — Scalable Vector Graphics container.
- [ ] `<math>` — MathML for mathematical notation.

## 7. Tables
- [ ] `<table>` — Table container.
- [ ] `<caption>` — Table caption.
- [ ] `<thead>` — Table header row group.
- [ ] `<tbody>` — Table body row group.
- [ ] `<tfoot>` — Table footer row group.
- [ ] `<tr>` — Table row.
- [ ] `<td>` — Table data cell.
- [ ] `<th>` — Table header cell.
- [ ] `<col>` — Column definition.
- [ ] `<colgroup>` — Group of columns.

## 8. Forms
- [ ] `<form>` — Form container.
- [ ] `<label>` — Label for form input.
- [ ] `<input>` — User input field (text, email, number, etc.).
- [ ] `<textarea>` — Multi-line input field.
- [ ] `<button>` — Clickable button.
- [ ] `<select>` — Drop-down menu.
- [ ] `<option>` — Option in a `<select>`.
- [ ] `<optgroup>` — Group of options in `<select>`.
- [ ] `<fieldset>` — Groups related form controls.
- [ ] `<legend>` — Caption for `<fieldset>`.
- [ ] `<datalist>` — Predefined options for `<input>`.
- [ ] `<output>` — Result of a calculation.
- [ ] `<progress>` — Progress indicator.
- [ ] `<meter>` — Scalar measurement indicator.

## 9. Interactive Elements
- [ ] `<details>` — Disclosure widget (expand/collapse).
- [ ] `<summary>` — Summary for `<details>`.
- [ ] `<dialog>` — Dialog box / modal.

## 10. Scripting
- [ ] `<script>` — JavaScript code.
- [ ] `<noscript>` — Content when JS is disabled.
- [ ] `<canvas>` — Scriptable graphics area.
- [ ] `<slot>` — Web Component insertion point.
- [ ] `<template>` — Inert DOM fragment.

---

## 11. Global Attributes (apply to most elements)
- [ ] `id` — Unique identifier.
- [ ] `class` — CSS class name(s).
- [ ] `style` — Inline CSS styles.
- [ ] `title` — Tooltip text.
- [ ] `lang` — Language of element.
- [ ] `dir` — Text direction.
- [ ] `hidden` — Hides the element.
- [ ] `tabindex` — Keyboard navigation order.
- [ ] `accesskey` — Keyboard shortcut.
- [ ] `draggable` — Whether element can be dragged.
- [ ] `contenteditable` — Makes element editable.
- [ ] `spellcheck` — Enables spell checking.
- [ ] `translate` — Should element content be translated?
- [ ] `data-*` — Custom data attributes.

---

## 12. Accessibility (ARIA Attributes)

- [ ] role — Defines semantic role (button, dialog, etc.)
- [ ] aria-label — Accessible name
- [ ] aria-labelledby — Links to label element
- [ ] aria-describedby — Links to description
- [ ] aria-hidden — Hides from assistive tech
- [ ] aria-expanded — State of expandable item
- [ ] aria-pressed — State of toggle button
- [ ] aria-checked — Checkbox/radio state
- [ ] aria-selected — Selection state
- [ ] aria-live — Dynamic content region (polite, assertive)
- [ ] aria-busy — Marks element as loading
- [ ] aria-controls — Identifies controlled element(s)
- [ ] aria-current — Marks current item in a set

 ---

## 13. Deprecated / Obsolete Elements (don’t use, but may appear in old code)
- [ ] `<acronym>` — Replaced by `<abbr>`.
- [ ] `<applet>` — Use `<object>` instead.
- [ ] `<basefont>` — Use CSS instead.
- [ ] `<big>` — Use CSS `font-size`.
- [ ] `<center>` — Use CSS `text-align`.
- [ ] `<font>` — Use CSS instead.
- [ ] `<frame>`, `<frameset>`, `<noframes>` — Use `<iframe>`.
- [ ] `<marquee>` — No direct replacement, use CSS animations.
- [ ] `<strike>` — Use `<s>` or `<del>`.
- [ ] `<tt>` — Use CSS `font-family: monospace`.
